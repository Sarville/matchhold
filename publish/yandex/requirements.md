# Яндекс.Игры: требования кабинета и статус материалов

Источник требований: справочник скилла `yandex-vk-integration` (`reference/publish-materials.md`). Кабинета пока нет — всё готово к загрузке, ничего не опубликовано.

## Картинки и видео

| Что | Требование | Файл | Статус |
|---|---|---|---|
| Иконка | 512×512, PNG | `icon/icon_512.png` | готово (без текста — один на все языки) |
| Обложка | 800×470, PNG | `cover/ru/cover_800x470.png`, `cover/en/cover_800x470.png` | готово (с названием — свой файл на язык) |
| Скриншоты RU | ≥3, 16:9, 1280–2560 по длинной стороне, JPEG/PNG без альфы | `screenshots/ru/01…05_*.jpg` (1920×1080, RGB) | готово, 5 шт. |
| Скриншоты EN | то же | `screenshots/en/01…05_*.jpg` | готово, 5 шт. |
| Горизонтальное видео | 16:9, 1920×1080 (не ниже 1280×720), ≤25 с | `video/ru/gameplay_1920x1080.mp4`, `video/en/…` | готово, 24,5 с, H.264 без звука, ~7 МБ |
| Вертикальное видео | необязательно | — | не делали |
| Рекламные видео | необязательно | — | не делали |

Тип скриншотов в кабинете: «Десктопные» (снято в окне 1920×1080; игра портретная, поле по центру, фон закрывает боковые стороны — без растяжения). Мобильные скриншоты 9:16 при желании можно снять тем же скриптом съёмки (в репозиторий он не входит).

Скриншоты честные: реальные кадры игры (титул, день, ночь, монстры, дракон), без отладочных элементов. В кадре штатный значок меню в углу.

## Тексты

Все тексты — в `description.md` (RU и EN, с лимитами и счётчиком длины).

| Поле | Лимит |
|---|---|
| Название | ≤50 |
| Описание для SEO | ≤160 |
| Об игре | ≤1000 |
| Короткое описание | ≤70 |
| Как играть | ≤1000 |
| Ключевые слова | ≤100, через запятую |
| Теги | свободные |

## Параметры формы

- Возрастной рейтинг: **6+**.
- Категория: **Головоломки**.
- Языки: **RU, EN** (у каждого свой комплект обложки, скриншотов и видео).
- Облачные сохранения: используются (SDK платформы).
- Реклама: интерстишл + баннер (Яндекс Реклама); покупка `disable_ads` («Отключить рекламу») в кабинете создаётся вручную.

## Загружать руками

1. Собрать zip Яндекс-сборки (`tools/build_platform.py`, см. корневой README/сборки) и загрузить черновик.
2. Заполнить формы описания на RU и EN из `description.md`.
3. Загрузить иконку, обложки, скриншоты и видео по языкам.
4. Создать в кабинете товар `disable_ads`, включить рекламу и облачные сохранения.
5. Отправить на модерацию — только после подтверждения владельца.
