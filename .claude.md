# Matchhold

- Ребрендинг арта: план, промпты и референсы в `rebranding/` (входная точка `rebranding/README.md`).
- Сгенерированное лежит в `rebranding/out/`. В `www/` арт попадает только после ревью Claude.
- Игра: сцена 600×650 (портрет 600×725), поле 8×8, спрайты работают по схеме «ряд = действие, колонка = кадр» (`graphics.js` `updateSprite`).
- Сборка `deploy`: команда r.js в `rebranding/archive/tiles-plan-v1.md`, п. 6 (или `ant deploy`), затем скопировать `build/` в `deploy/`.
- Итоги сессий: `sessions/`.
- Генерация арта: codex CLI, `gpt-5.6-terra`, reasoning low (`codex exec -m gpt-5.6-terra -c model_reasoning_effort=low --sandbox workspace-write "<промпт>" -i <реф…>`; промпт ставить ДО `-i`). Готовые скрипты и промпты: `rebranding/tools/gen/`.
- Прозрачность от кодекса ненадёжна и он сам её не проверяет: после генерации замерять альфу; запасной путь фон `#FF00FF` + `rebranding/tools/key_layer.py`. Не просить «центр N% пуст» у слоёв (получаются прямые срезы).
- Актуальные решения по арту (тонкая рамка 150 px, фон в 3 слоя, размеры мастеров, единые панели HUD, порядок слоёв) в `rebranding/README.md`, раздел «Актуально после сессии 2». Задачи: `rebranding/TODO.md`. Журнал арта: `rebranding/out/LOG.md` (ведём по формату из README).
- Моки собирает `rebranding/tools/mock_all.py` (из `rebranding/out`), устаревшие уходят в `rebranding/out/archive/mocks/`.
- `rebranding/out/` весит ~264 МБ (мастера PNG): не коммитить целиком без решения пользователя; в git идут `LOG.md`, `tools/`, доки.
- Начало новой сессии: прочитать `rebranding/TODO.md` и хвост `rebranding/out/LOG.md`.
- Плитки готовы (65 граней, листы в `rebranding/out/tiles/sheets/`, манифест `rebranding/tiles-manifest.json`); пересборка `python3 rebranding/tools/build_tiles.py` из `rebranding/`. Ключ фона: фиолетовое/розовое только на `#00FF00`. Раздел «Плитки (сессия 3)» в `rebranding/README.md`.
- Не коммитить `rebranding/out/` целиком и `__pycache__`; коммитятся `LOG.md`, `tools/`, доки, `tiles-manifest.json`. Удалённого репозитория нет (`git remote` пуст): push недоступен.
