# Matchhold: ребрендинг арта

Этот файл читает агент-генератор **первым**. Здесь общие правила для всех артов. Конкретные списки и промпты лежат в четырёх документах:

| Документ | Что внутри |
|---|---|
| [01-environment.md](01-environment.md) | рамка поля, подложка, фоны (день/ночь/дракон), передний план, здания, капсулы ресурсов, небо и мелочь |
| [02-tiles.md](02-tiles.md) | плашки плиток (день/ночь), иконки ресурсов (день, ночь, дракон), сборка плитка = плашка + иконка |
| [03-animation.md](03-animation.md) | герой, 14 монстров, дракон: реф-листы и покадровые спрайт-листы |
| [04-icons-and-misc.md](04-icons-and-misc.md) | HUD (сердца, меч, щит, опыт), лут, заклинания, кнопки, титул, значок |

## Роли

- **Агент-генератор** (вы): генерирует картинки по промптам и кладёт их в `out/`. В проект ничего не добавляет и код не трогает.
- **Claude**: смотрит результат, принимает или возвращает на доработку, нарезает/собирает листы, встраивает в `www/`.
- **Пользователь**: утверждает стиль на контрольных точках (гейтах).

Папки создавайте сами по мере надобности. Ничего вне `rebranding/out/` не создавайте и не меняйте.

## Как работать

1. Прочитайте этот файл и нужный документ целиком, посмотрите все рефы из раздела «Рефы» нужного арта.
2. Полный промпт собирается так: `STYLE-блок (день или ночь) + промпт арта из таблицы + TECH-хвост`. Блоки лежат ниже.
3. Прикладывайте к запросу референсы, которые указаны у арта. Без реф-картинки стиль не удержится.
4. Сохраняйте результат: `out/<группа>/<id>_v<N>.png` (`v1`, `v2`…). Существующие файлы не перезаписывайте.
5. После каждого файла добавляйте строку в `out/LOG.md`:
   `id | файл | реф(ы) | ключ фона или alpha | заметка | статус: pending`
6. Останавливайтесь на **гейтах** (помечены «🛑 Гейт» в документах) и ждёте ответа. Дальше гейта не генерируйте.
7. Количество вариантов: якорные арты (плашки, якорные иконки, рамка, реф-листы героя и монстров) 3 варианта, остальное 1–2.
8. Ревью: Claude пишет в `LOG.md` статус `approved` или `redo: <причина>`. По `redo` делайте новую версию `_v<N+1>`, исправляя именно названную причину.

## Технические правила для любого файла

- Формат PNG RGBA. Мастера крупные, ужимает Claude. Размеры указаны у каждого арта.
- **Один арт: один файл.** Не рисуйте сетки и листы из разных объектов, кроме случаев, когда документ прямо требует ленту (серии иконок, полосы кадров).
- **Фон.** Если модель умеет настоящую прозрачность (например `background: transparent`), используйте её. Иначе сплошной ключ-фон: `#FF00FF` по умолчанию; если в арте есть пурпур/розовый, то `#00FF00`; если и зелёный, то `#00FFFF`. Без градиентов, теней и текстуры на фоне, без каймы. Ключ пишите в `LOG.md`.
- **Никакого текста**: ни букв, ни цифр, ни логотипов, ни водяных знаков, ни подписей.
- **Ничего лишнего в кадре.** Арт не содержит того, что игра рисует сама (см. «Не запекать» в каждом документе).
- Свет всегда сверху-слева, тень вниз-вправо. Ракурс предметов: три четверти сверху, кроме мест, где указано иное.
- Читаемость: арт должен быть понятен, если уменьшить его до 52 px (плитка) или 60×80 px (здание).

## STYLE-блоки

### DAY

```
Cozy fantasy village match-3 game art. Warm, soft, matte hand-painted 3D look:
chunky rounded forms, soft ambient occlusion, gentle gradients, NO glossy plastic
highlights, NO specular shine, NO glassy sparkle. Warm afternoon light from the
top-left, soft warm shadow toward the bottom-right. A thin outline slightly darker
than the object's own hue (about 2-3% of the object size), never black. Clean,
readable silhouette. Palette: warm sand beige, honey gold, chestnut brown, sage
green, muted terracotta, cream white.
```

### NIGHT

```
Cozy fantasy match-3 game art at night. Same warm, soft, matte hand-painted 3D look
as the day art (chunky rounded forms, soft ambient occlusion, NO glossy plastic
highlights). Deep indigo and navy shadows, cool moonlight from the top-left, warm
torch-orange accents, soft rim light and a gentle glow on key details. Thin outline
slightly darker than the object's own hue, never black. Clean, readable silhouette
against dark backgrounds.
```

### NEGATIVE (добавлять всегда, если модель поддерживает негативный промпт; иначе дописать в конец как «Avoid: …»)

```
text, letters, numbers, logos, watermark, signature, UI overlay, photorealism,
harsh gloss, lens flare, pixel art, thick black outlines, extra objects, cropped
edges, blurry subject, multiple views, collage.
```

## Палитра классов ресурсов

Используется и днём, и ночью (ночью подсвечивается glow-ом, оттенок не меняется).

| Класс | Цвет | Материал |
|---|---|---|
| grain | тёплое золото `#F2C14E` | пшеница, хлеб, мясо |
| wood | каштановый `#7C5840` | дерево, доски |
| stone | холодный серый `#9AA0A6` (выше уровни: тёмный, затем голубой) | камень, слитки |
| clay | терракота `#C65645` | глина, кирпичи |
| cloth | фиолетовый `#7E57C2` со светлыми складками | ткань |
| mana | пурпурно-розовый `#D94FA8` | кристалл |

Ткань в эталоне (`ref-day-tiles.png`) кремово-белая. На бежевой плашке она сливается, поэтому в новой серии основной цвет ткани фиолетовый, а кремовый остаётся для бликов и подкладки. Это отклонение, оно утверждается на гейте 1 в `02-tiles.md`.

## Общая геометрия игры (для справки, менять нельзя)

- Логическая сцена 600×650 (десктоп) или 600×725 (телефон, портрет). Меньше экрана масштабируется вниз, больше не растёт.
- Поле 8×8 плиток. Клетка 60 px (десктоп) или 70 px (портрет). Значит доска квадратная (480×480 / 560×560).
- Над доской полоса мира 600×110: днём здания и герой, ночью герой и монстры. Земля этой полосы = верхний край рамки.
- День и ночь переключаются плавно за 1,4 с (crossfade). Значит у всего, что меняется (рамка, подложка, фон, плитки), есть парные день/ночь версии одинаковой геометрии.
