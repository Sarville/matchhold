# Скрипты генерации (как получены арты)

Копии рабочих скриптов сессии 2 (2026-09-25). Внутри полные промпты. Пути `S=/tmp/claude-…/scratchpad` временные: перед запуском заменить на свою папку логов.
Порядок в одном скрипте: `gen()` = `codex exec -m gpt-5.6-terra -c model_reasoning_effort=low --sandbox workspace-write "<промпт>" -i <реф1> <реф2>`.
ВАЖНО: `-i` принимает список файлов, промпт ставить ДО `-i`, иначе промпт съедается как файл.

| Скрипт | Что делает |
|---|---|
| `gen_day.sh` | первые дневные рамка (толстая), подложка, лунка (устарело, толстая рамка) |
| `gen_night.sh` | ночные толстая рамка, подложка, лунка (устарело) |
| `gen_bg.sh`, `gen_bg2.sh` | полноэкранные фоны s1 (устарело, остались как референс сцены) |
| `gen_thin.sh` + `frame_guide_thin.png` | тонкая дневная рамка по схеме-кольцу (гайд задаёт геометрию: 150 px, проём 182..1865) |
| `gen_layers.sh`, `gen_layers2.sh` | ночная тонкая рамка; дальний/средний/передний слой s1 land (день, ночь) |
| `gen_stages.sh` | дальний и средний слои s2–s4 land |
| `gen_ports1.sh`…`gen_ports5.sh` | дальние/средние/передние слои портрета; ports1 = тест настоящей прозрачности; ports4/5 = передний слой портрета «пучки внизу» |
| `gen_hud.sh` | HUD-набор (сердца, слоты, панель инвентаря, полоса), зелья, заклинания |
| `gen_panels.sh` | пустая плашка панелей и лиана |
| `gen_sock3.sh`, `gen_more.sh` | тонкая лунка день v3, ночь v2, иконки бомбы/экипировки/свитка |
| `gen_socket.sh` | лунка день v2 с чистым ключом |
